EPIC: Dashboard Overview & Core Insights
US‑001: Power Overview Snapshot
As a homeowner,
I want to see the latest household power consumption at the top of the dashboard,
so that I immediately understand my current electricity usage when opening the app.

US‑002: Data Freshness Awareness
As a homeowner,
I want to see the date and time of the most recent measurement,
so that I know how up‑to‑date the displayed information is.

EPIC: Time‑based Consumption Analysis
US‑003: Consumption Timeline Visualization
As a homeowner,
I want to see my household power consumption plotted over time,
so that I can visually identify trends, spikes, and unusual patterns.

US‑004: Time Range Exploration
As a homeowner,
I want to zoom into a specific day or week in the consumption timeline,
so that I can investigate interesting periods in detail.

US‑005: Top Consumption Hours Insight
As a homeowner,
I want to see the top 3 hours of the day with the highest average consumption,
so that I know when I should be most conscious of my energy usage.

EPIC: Energy Breakdown & Comparison
US‑006: Appliance Zone Comparison
As a homeowner,
I want to compare daily energy consumption across kitchen, laundry, and heating/AC,
so that I immediately understand where most energy is being used.

US‑007: Sub‑Metering Consumption Breakdown
As a homeowner,
I want to see how my total energy consumption is split between appliance zones,
so that I know which areas offer the biggest potential for energy savings.

US‑008: Period‑based Zone Comparison
As a homeowner,
I want to filter the appliance breakdown by day or week,
so that I can compare my habits across different time periods.

EPIC: Daily & Standby Consumption Awareness
US‑009: Daily Total Consumption
As a homeowner,
I want to see the total energy consumed on the most recent day,
so that I can quickly judge whether it was a high or low usage day.

US‑010: Standby Load Visibility
As a homeowner,
I want to see my average power consumption during the night,
so that I can estimate how much energy my standby devices are wasting.

EPIC: Electrical Health Monitoring
US‑011: Voltage Health Indicator
As a homeowner,
I want a visual indicator that shows whether my supply voltage is normal, marginal, or critical,
so that I can spot potential electrical issues at a glance.

US‑012: Current Intensity Awareness
As a homeowner,
I want to see my current electrical load in amps,
so that I understand the risk of overloading my circuits.

US‑013: Reactive Power Warning
As a homeowner,
I want to be warned when my power factor becomes poor,
so that I can avoid unnecessary energy losses and potential tariff penalties.

EPIC: Alerts, Intelligence & Optimization
US‑014: Peak Consumption Detection
As a homeowner,
I want to be alerted when my household enters a peak consumption phase,
so that I can take action before my electricity costs increase.

US‑015: Peak Event History
As a homeowner,
I want to view a history of past consumption peaks,
so that I can understand long‑term patterns and recurring behaviours.

US‑016: Configurable Peak Detection
As a product owner,
I want peak detection thresholds to be configurable,
so that the system can be tuned per household without code changes.

US‑017: Anomaly Detection
As a homeowner,
I want the system to detect unusual deviations from my normal usage patterns,
so that I can investigate appliance faults, unexpected loads, or security issues early.

US‑018: Visual Anomaly Context
As a homeowner,
I want detected anomalies to be highlighted directly on the consumption timeline,
so that I can visually understand when and how my usage deviated.

US‑019: Weekly Consumption Summary
As a homeowner,
I want a weekly comparison of my energy consumption by zone,
so that I can track whether my energy‑saving efforts are working.

EPIC: Data Transparency & Trust
US‑020: Raw Data Table Access
As a homeowner,
I want to browse the raw consumption measurements in a paginated table,
so that I can inspect individual readings without being overwhelmed.

US‑021: Date‑Filtered Data View
As a homeowner,
I want to filter the raw data table by date,
so that I can focus on specific days or periods.

US‑022: Dataset Scope Awareness
As a homeowner,
I want to see how many records are loaded and which dates they cover,
so that I understand the scope and limits of the data I’m viewing.

EPIC: Usability & Experience
US‑023: Loading Feedback
As a homeowner,
I want to see placeholder content while the data is loading,
so that the app feels responsive and trustworthy.

US‑024: Dark Mode Preference
As a homeowner,
I want to switch between light and dark mode and have my choice remembered,
so that I can comfortably use the dashboard in different lighting conditions.

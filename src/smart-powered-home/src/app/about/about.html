Smart Powered Home

v1.0.0

About the Application

Smart Powered Home is an interactive energy monitoring dashboard that visualises household power consumption data in real time. Built as a modern single-page application, it provides homeowners with actionable insights into their energy usage patterns, helping them identify waste, optimise consumption, and reduce electricity costs.

Key Features

  • Live Power Overview — real-time global active power, voltage, and current intensity readings
  • Interactive Timeline Chart — line chart with day/week views and date selection
  • Sub-Metering Breakdown — doughnut chart comparing kitchen, laundry, and heating/AC zones
  • Peak Shaving Alerts — configurable threshold-based peak detection with event logging
  • Anomaly Detection — Z-score-based identification of unusual consumption patterns
  • Voltage Status Indicator — colour-coded supply health monitor (normal / marginal / critical)
  • Zone Comparison Bars — horizontal CSS bars for at-a-glance appliance zone comparison
  • Standby Load Indicator — overnight base load estimation to spot "silent" energy waste
  • Reactive Power Warning — power factor calculation with poor-PF alerts
  • Paginated Data Table — server-side paginated access to all 148,000+ raw records
  • Dark, Light & Wednesday Themes — three distinct visual themes including a gothic-inspired design

Technology Stack

Frontend Angular 21, PrimeNG, Chart.js, SCSS
Backend .NET 10 Web API, LiteDB, SignalR
Real-Time SignalR WebSocket hub with live data simulation
Testing Vitest (unit), Playwright (E2E)

Data Source

The application uses the Individual Household Electric Power Consumption dataset, containing approximately 148,000 minute-resolution measurements of a single household's electrical parameters including global active/reactive power, voltage, current intensity, and three sub-metered zones (kitchen, laundry, heating/AC).

Development Team

Designed and developed by the GoG team as part of a workshop-style MVP project. The application demonstrates modern full-stack development practices including signal-based state management, server-sent real-time updates, and comprehensive automated testing.
